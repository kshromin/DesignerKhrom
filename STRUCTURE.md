# Структура проекта — DesignerKhrom

Коротко, для ориентира. Подробности читаются по коду. **Обновлять при любом изменении структуры**,
держать так же коротко.

Статический сайт без сборки: `index.html` + JS-модули в браузере, Three.js.

## Файлы

- `ТЗ.md` — замысел и модель данных. Читать первым.
- `DEVLOG.md` — журнал сессий.
- `CLAUDE.md` — инструкции и правила работы.
- `index.html` — страница: область 3D + панель справа (габарит, палитра, цепочка). Three.js
  подключён с CDN через importmap.
- `css/style.css` — оформление, намеренно скупое.
- `js/model.js` — **данные**: застройка, детали, просветы, пересчёт цепочки, подписка на изменения.
  Не знает ни о Three.js, ни о DOM.
- `js/scene.js` — **3D**: камера, вращение, границы застройки, детали. Читает модель, не меняет её.
- `js/ui.js` — **интерфейс**: поля габарита, палитра видов деталей, список цепочки. О 3D не знает.
- `js/main.js` — точка входа, связывает три слоя.
- `scripts/dev-server.py` — локальный сервер без кэша. Конфиг `designer`, порт **8730**.
- `_work/` — рабочая папка, в `.gitignore`, на GitHub не уезжает.

## Принцип разделения

Слои разделены с первого дня, чтобы не повторить главную беду первого конфигуратора, где `tabs.js`
вырос до 1676 строк и стал узким горлом для всего. Связь односторонняя:

    ui.js  →  model.js  →  scene.js

Панель меняет модель, модель уведомляет сцену. Сцена и панель друг о друге не знают, модель не знает
ни о ком. Так модель можно проверять и менять отдельно от отрисовки.

## Как устроена цепочка (`model.js`)

Главный инвариант: **сумма просветов и толщин деталей строго равна ширине застройки**. Координаты
не хранятся — `computeLayout()` разворачивает цепочку слева направо и выдаёт координаты деталям
и просветам. Любая операция обязана сохранить инвариант: разъехавшийся — это изделие, которое
не соберётся.

Пока цепочка **одна и одномерная**: вертикальные стойки делят застройку по ширине во всю высоту
и глубину. Полки потребуют второго измерения — см. открытый вопрос в DEVLOG.

## Чего ещё нет (по ТЗ)

Полки и привязка по высоте, задние щиты, внешние детали, подсветка мест установки в 3D, размеры
на модели, узлы (ящики, двери, штанги), каталог материалов, цена, отмена действия.
